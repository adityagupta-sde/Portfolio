# 🌐 Aditya Gupta - Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, certifications, and experience as a Java Backend Developer.

The portfolio is designed with a clean dark theme, smooth animations, responsive layouts, and interactive sections.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern dark-themed UI
- Animated hero section with typewriter effect
- About Me section
- Skills & Expertise section
- Featured Projects section
- Certificates section
- Contact form with Formspree integration
- WhatsApp contact option
- LinkedIn and GitHub integration
- Resume download
- Smooth scrolling navigation
- Scroll-based animations
- Mobile-friendly navigation menu
